Nuevo Producto

Selecciona una combinación guardada para cambiar su talla, color o precio. También se muestran las variantes inactivas y sin stock.

1. Datos del producto

Precio que aparece en el catálogo. Cada talla y color puede tener su propio precio.

2. Talla, color y existencias

Una variante es una sola talla y un solo color. Ejemplo: talla S, color Negro, 5 unidades. Para M y L, usa «Añadir variante» por separado.

Escribe una talla. No escribas S-M-L ni varias tallas juntas. Si guardaste una así, reemplázala por una talla y revisa cuántas unidades le corresponden.

Cuenta únicamente las unidades de esta combinación. Con 0 unidades no se podrá elegir para comprar.

Ejemplo: +5 añade cinco unidades; -2 retira dos. Este ajuste se guarda con su propio botón.

Para comprar, el producto y la variante deben estar activos y tener stock mayor que cero.

3. Fotos del producto

Selecciona hasta 8 fotos JPG o PNG. Máximo 5 MB cada una. La primera será la portada.
